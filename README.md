# MatchStrike Web

Фронтенд сообщества Counter-Strike: Source v34: серверы, матчи Mix и War, рейтинг, профили, друзья, обращения и административная панель. Работает с отдельным Laravel API; игровые данные поступают через веб-мосты DonutMatch и DonutStats.

## Возможности

- Список игровых серверов с картой, режимом и онлайном.
- Отдельные списки Mix и War: сначала 10 матчей, затем подгрузка по 10 при прокрутке.
- Страница матча со счётом, длительностью, составами и статистикой игроков.
- War Classic, BO1, BO3 и BO5; результаты карт, суммарная и покарточная статистика серии.
- Выбор и запрет карт с указанием команды, если эти данные передал плагин.
- Обновления матча через WebSocket с резервным опросом API.
- War-рейтинг с поиском по никнейму и Steam ID, значками уровней ELO.
- Профиль, активность Mix и War, история матчей, подробная War-статистика, оружие и клатчи.
- Регистрация, вход, двухфакторная аутентификация, настройки профиля и сеансов.
- Друзья, уведомления, поддержка, жалобы и административные разделы.
- Светлая и тёмная темы, адаптивная вёрстка и устанавливаемое PWA.

Фронтенд не подставляет демонстрационные матчи или выдуманные значения вместо отсутствующей статистики. Права доступа проверяются в API; клиентские ограничения интерфейса их не заменяют.

## Локальный запуск

Требуются Node.js 20+ и npm. Стек: Vue 3, TypeScript, Vite 6, Tailwind CSS 4. Точные версии фиксирует `package-lock.json`.

В PowerShell из каталога репозитория:

```powershell
npm.cmd ci
npm.cmd run dev
```

Основной адрес — `http://127.0.0.1:5173`. Если порт занят, Vite предложит другой; точный адрес указан в терминале. В Linux/macOS используйте `npm` вместо `npm.cmd`.

В другом терминале запустите API на `http://127.0.0.1:8000` по инструкции [MatchStrike API](../MatchStrike-API/README.md). В рабочем окружении репозитории расположены рядом:

```text
Projects/
├── MatchStrike/      # Этот репозиторий
└── MatchStrike-API/  # Laravel API
```

Отдельный `.env` для базового запуска фронтенда не требуется: запросы используют относительный адрес `/api/v1`.

## Команды разработки

| Команда | Назначение |
| --- | --- |
| `npm.cmd ci` | Установка зависимостей из lock-файла |
| `npm.cmd run dev` | Сервер разработки |
| `npm.cmd run typecheck` | Проверка Vue и TypeScript без сборки |
| `npm.cmd test` | Тесты через Node.js test runner |
| `npm.cmd run build` | Проверка типов, сборка приложения и service worker в `dist/` |
| `npm.cmd run preview` | Просмотр production-сборки |

В текущей конфигурации Vite preview наследует `server.proxy` и также ожидает API на порту 8000. После `npm.cmd run build` можно запустить `npm.cmd run preview`; адрес появится в терминале. `preview` не предназначен для production.

Тесты проверяют агрегацию игроков серии, недоступность API и позиционирование подсказок. CI в `.github/workflows/ci.yml` устанавливает зависимости и выполняет сборку; `npm test` запускается отдельно.

## Связь с API

В [vite.config.ts](vite.config.ts) `/api/*` и `/uploads/*` проксируются на `http://127.0.0.1:8000`. При изменении порта API исправьте `server.proxy` и перезапустите Vite. Не смешивайте `localhost` и `127.0.0.1` при работе с cookie.

Авторизация использует cookie-сеанс. Перед изменяющими запросами клиент получает CSRF-токен через `/api/v1/auth/csrf`. Секреты Reverb и bearer-токены игровых плагинов во фронтенде не хранятся.

Общий транспорт — [src/apiTransport.mjs](src/apiTransport.mjs). При сетевой ошибке, HTTP 5xx, некорректном JSON в успешном ответе или ожидании дольше 15 секунд появляется окно «Сайт не отвечает» с GIF и кнопкой обновления. Его можно закрыть крестиком или Escape; одновременные ошибки не создают несколько окон. Ответы 401, 403, 404, 422 и 429 обрабатываются страницами без этого окна.

## Матчи и статистика

| Путь | Назначение |
| --- | --- |
| `/` | Главная и серверы |
| `/matches/mix`, `/matches/war` | Матчи выбранного режима |
| `/matches/{id}` | Подробности матча |
| `/stats` | Рейтинг игроков |
| `/profile/{nickname}` | Публичный профиль |
| `/bans` | Блокировки игровых серверов |
| `/friends`, `/tickets`, `/settings` | Разделы вошедшего пользователя |
| `/adminpanel` | Административная панель |

Список матчей опрашивает API каждые 15 секунд, пока вкладка видима. На странице матча Pusher-клиент подключается к Laravel Reverb по параметрам API. Событие `match.updated` передаёт ID матча и вызывает загрузку подробностей. Если WebSocket не подключён, используется опрос каждые 5 секунд. Возврат на вкладку также обновляет данные.

В live-серии крупно показывается счёт текущей карты, счёт по картам — отдельно. После завершения доступны суммарная и покарточные таблицы, если плагин передал данные. Длительность форматируется из `durationSeconds`, а не вычисляется из времени обновления страницы.

Основная статистика и рейтинг основаны на War. Календарь активности учитывает завершённые Mix и War за 365 дней; на узких блоках отображаются последние 18 недель, примерно четыре месяца. Связанная BO-серия считается одним матчем. Для связи истории с профилем нужен привязанный Steam ID.

| Показатель | Значение | Точность |
| --- | --- | --- |
| ELO | Накопительный War-рейтинг плагина | Целое число и значок уровня |
| KDR / K/D | Убийства / смерти | 2 знака после точки |
| HS% | Хедшоты / убийства × 100 | 1 знак |
| AVG | Убийства / War-матчи в профиле плагина | 1 знак |
| ADR | Урон / раунды | 1 знак |
| DPR | Смерти / раунды | 2 знака |
| KAST | Доля раундов с убийством, ассистом, выживанием или разменом | 1 знак |
| Winrate | Победы / матчи × 100 | 1 знак |

История сайта может быть короче накопительного профиля плагина: автоматического импорта всей игровой БД нет. В плагине отдельная War-карта участвует в обновлении профиля; календарь сайта объединяет карты связанной серии.

## Темы и ресурсы

Базовая вёрстка — `src/home.css`, темы — `src/theme.css`. Tailwind подключён через Vite-плагин.

Для подсказок используйте глобальную директиву `v-tooltip`, а не HTML-атрибут `title`:

```vue
<button v-tooltip="'Обновить данные'" aria-label="Обновить данные">...</button>
<span v-tooltip="description">ADR</span>
```

В тёмной теме подсказка имеет чёрно-синий градиент, в светлой — белый фон и чёрную окантовку. Поддерживаются фокус, Escape, изменение текста и границы экрана. Текст вставляется без HTML. `aria-label` для кнопок с одними иконками задаётся отдельно.

| Ресурс | Расположение |
| --- | --- |
| Логотипы и иконки приложения | `public/icons/symbols/` |
| Значки уровней ELO | `public/icons/levels/` |
| GIF окна недоступности | `public/other/cat-cat-dance.gif` |
| Изображения карт | `/uploads/maps/` на API |

Например, `de_dust2.webp` используется для `de_dust2_ob` и `dust2_2x2`. Для `cs_` префикс сохраняется; без префикса используется `de_`. Персонажи — `ct.png` и `tt.png` в той же папке API. Правила находятся в `src/matchArtwork.ts`.

## PWA

Manifest — `public/manifest.webmanifest`, service worker — `src/sw.js`. Сборка использует Workbox и `injectManifest`.

- Оболочка и выбранные статические ресурсы кешируются; API-запросы остаются сетевыми.
- Новая версия активируется после подтверждения в интерфейсе.
- Офлайн-оболочка не даёт доступ к матчам, входу и настройкам без API.
- Push требует VAPID-ключей на API и разрешения пользователя.
- Для установки и push нужен HTTPS или допустимое локальное окружение. На iOS push используется из установленного веб-приложения.

Поведение service worker проверяйте на production-сборке, а не только на Vite dev server.

## Production и Docker

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
```

Публикуется `dist/`. Веб-сервер возвращает `index.html` для маршрутов Vue и направляет `/api/*` и `/uploads/*` в API. WebSocket `/app/*` проксируется в Reverb отдельно.

В [Dockerfile](Dockerfile) Node собирает приложение, Nginx обслуживает результат:

```powershell
docker build -t matchstrike-web:local .
```

[docker-nginx.conf](docker-nginx.conf) ожидает API по имени `matchstrike-api:80`. Нужна общая Docker-сеть и этот DNS alias либо изменение конфигурации. Compose-файла в репозитории нет. HTTPS, домен и WebSocket настраиваются во внешнем reverse proxy.

## Диагностика

| Симптом | Что проверить |
| --- | --- |
| «Сайт не отвечает» | Процесс API, `/api/v1/health`, proxy и ответ в Network |
| Есть K/D, остальные столбцы пустые | Поле `donutStats` в API; отдельный URL DonutStats — см. README API |
| Длительность — прочерк | `durationSeconds`, версию DonutMatch Web и завершённые события DonutStats |
| Нет realtime | Параметры `realtime` в API, процесс Reverb и прокси `/app/` |
| Нет активности игрока | Steam ID, участие в сохранённых завершённых матчах, период календаря |
| После публикации видна старая версия | Подтверждение обновления PWA, новый `sw.js`, кеш reverse proxy |
| Прямая ссылка на профиль или матч даёт 404 | SPA fallback на `index.html` |
| `npm.ps1` блокируется PowerShell | Использовать `npm.cmd` |

Настройка игровых плагинов, баз и серверных переменных — в [README API](../MatchStrike-API/README.md).
